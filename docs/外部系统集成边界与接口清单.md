# ChemAgent 外部系统集成边界与接口清单

> 版本：0.1（草案）
> 用途：约束产品边界，避免 ChemAgent 向 ERP/PLM/LIMS 流程系统扩散。

## 1. 定位

ChemAgent 是化学研发的 **AI 与数据内核**，不是 PLM/LIMS/ERP。

内部专注：

- 配方、材料、实验、知识的结构化数据；
- AI 起草、分析、预测、检索；
- 数据导入/导出与可追溯版本。

内部不做：

- 审批流、任务分派、客户门户；
- 样品批次库存管理、生产工单；
- ERP 主数据管理、成本核算系统化；
- LIMS 检测流程与合规判定系统化。

## 2. 集成原则

1. 外部系统是流程与主数据的所有者时，ChemAgent 通过接口同步，不复制流程。
2. 默认单向或受控双向，不开放任意双向写库。
3. 每次外部写入/同步必须可追溯（记录来源系统、时间、操作人/服务账号）。
4. 对外统一 JSON/Excel/OpenAPI；企业私有协议（SAP RFC、LIMS 私有 API）以适配器扩展，不在核心内写死。
5. 字段冲突以文档中约定的主数据所有者为准。

## 3. 主数据与同步方向

| 数据 | ChemAgent | 外部系统 | 建议同步方向 |
|---|---|---|---|
| 配方版本 | 生成与版本管理 | PLM | ChemAgent → PLM（发布/变更） |
| 材料目录 | 科研用材料档案 | ERP/PLM | 双向：外部主数据 → ChemAgent，ChemAgent 变更回流 |
| 实验计划/样品 | 研发打样 | LIMS/ELN | ChemAgent → LIMS（送检/测试请求） |
| 检测结果 | 结构化接收 | LIMS | LIMS → ChemAgent（结果回流） |
| 成本/价格/库存 | 只读参考 | ERP | ERP → ChemAgent（只读） |

## 4. 接口清单

### 4.1 PLM 相关（最高优先）

目标：配方/物料/变更记录与 PLM 对齐。

- 配方详情 / 版本历史：`GET /api/formulas/{code}`、`GET /api/formula-versions/{code}`
- 配方导出/导入：`GET /api/formulas/export`、`POST /api/formulas/import`
- 配方列表检索：`GET /api/formulas`
- 配方状态（draft/review/approved/archived）：`PATCH /api/formulas/{code}/status`
- 材料检索/导出：`GET /api/materials`

同步策略：

- PLM 为发布主系统时，ChemAgent 提供“版本快照 JSON”作为 PLM 导入包；
- 配方在 ChemAgent 内修改后，由用户/事件触发生成“变更包”，人工确认后同步到 PLM。

### 4.2 LIMS 相关（高优先）

目标：ChemAgent 的 DOE/实验计划可送 LIMS，LIMS 检测结果可回流。

- 实验记录接口：`POST/GET/PATCH /api/experiments/results`
- 实验批量查询：`POST /api/experiments/query`
- 训练数据导出：`GET /api/experiments/export/training-data`
- DOE 方案：`POST /api/doe/generate`

同步策略：

- ChemAgent 实验计划 → 外部 LIMS（送样/检测任务）；
- LIMS 检测结果 → ChemAgent 实验记录（自动更新 measurements/spec 判定）；
- ChemAgent 不做 LIMS 的检测流程状态机。

### 4.3 ERP 相关（中优先）

目标：ChemAgent 能获取材料价格/库存，向 ERP 提供 BOM 成本信息。

- 材料只读同步：外部 ERP → ChemAgent；
- BOM/成本估算：`POST /api/cost/calculate`；
- 材料目录：`GET /api/materials`

同步策略：

- ERP 是材料价格/库存主系统；
- ChemAgent 不写 ERP；
- ERP 变化通过定时同步或事件推送更新 ChemAgent 只读参考。

## 5. 集成范围外（避免做成 PLM 的内容）

- 不实现审批工作流引擎；
- 不实现电子签名；
- 不实现客户门户/变更单；
- 不实现库存与生产批次管理；
- 不实现 LIMS 合规流程；
- 不实现 ERP 财务/供应链流程。

## 6. 建议实施顺序

1. 明确每类数据的对外契约（字段、格式、同步方向）；
2. 实现标准 JSON 导入/导出模板；
3. 先做 PLM 配方版本同步与 LIMS 检测结果导入两个样板；
4. 后续以适配器扩展 SAP/LIMS 私有协议。

## 7. 结论

ChemAgent 对外的价值是“让研发数据可被 AI 使用、可被外部系统消费”，
而不是替代外部系统。本文件作为后续功能与接口设计的边界约束。
